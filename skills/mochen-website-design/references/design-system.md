# 陌晨网站的设计约定

这套设计来自陌晨个人网站，参考 oiloil.org 的轻纸张、大字、细线与动效。保持视觉语言，栏目和内容密度按当前材料调整。

| 元素 | 约定 |
| --- | --- |
| 纸面 | #FFFFFF；固定 32px 网格，线透明度约 0.035 |
| 墨色 | 主标题 #1A1A1A，正文 #333333，辅助 #555555 |
| 强调 | #FFE28A；只用于选中、关键动作、下划线和少量标记 |
| 分隔线 | #ECECEA / #F2F1EE，1px |
| 阅读宽度 | 756px；横向作品页可适当扩展，长文保持约 65–75 字符 |
| 圆角 | 卡片 12px，控件 6–8px，避免全屏胶囊堆叠 |
| 字体 | 系统无衬线中文；编号、元信息用系统等宽字体 |
| 大标题 | 英文桌面最高 140px，平板约 92px，手机约 76px；中文按行长降低，最小屏不溢出 |
| 留白 | 以 8px 为基准；hero 到内容 56–96px，卡片间 18px |
| 图片 | 手绘操作员可以作签名插图；内容图要解释内容，避免重复装饰 |

人物保留黑发、眼镜、炭黑外套、MO 配置牌、青绿小光标。人物和小狗面向同一区域；小狗默认宽屏在右下，窄屏进入人物旁，拖动后变成独立浮层。

## 动效与状态

- 使用 `cubic-bezier(.22,.61,.36,1)`。按钮约 160–220ms，栏目约 420ms，卡片进入约 500–650ms；不同元素错开 60–90ms。
- 首屏大字与人物轻量进入，内容滚到视口再出现。卡片悬停上移 2–4px、略转动，点击有按下反馈；不要让阅读正文持续晃动。
- 大号栏目通过 hash 路由切换，有选中指示条，浏览器前进/后退可用。阅读页进入有过渡，返回回到原搜索和滚动位置。
- 人物微呼吸和眨眼，瞳孔随鼠标小幅移动；Gaze-Dog 用原始帧序列转头。拖拽本体 `touch-action:none`，页面其他区域保留正常滚动。
- `prefers-reduced-motion` 或 `?motion=reduce` 停止自动与装饰运动，不降低可用性。拖拽不使用惯性飞出屏幕，位置按可移动区域归一化保存。

## 内容编排

一个页面优先一个主要动作。可操作功能配真实控件，复杂流程配步骤和状态。文章长文用搜索、主题筛选、目录或阅读入口；产品内容用问题、功能、输入输出和案例；案例指标仅来自材料。无日期的数据不补时间线，无证书内容不创建证书栏。

手机以单列为主，导航可以横向滑动，点击目标至少 40px。避免 `overflow-x:hidden` 掩盖实际溢出；宽表格和代码块在各自区域滚动。
