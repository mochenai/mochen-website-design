# 陌晨个人网站使用说明

首页：Makes Things.；栏目：作品、Skills、文章、关于我、交流。

- 六个作品可以演示、展开详情；「个人网站设计skill」通向使用方法、开源仓库和下载。
- 118 篇文章支持搜索、分类、全文阅读与返回，返回保留列表位置。
- 工作经历以无日期卡片展示；没有教育与证书栏目。
- 交流区只展示公众号「Agent 陌晨」，可以复制名称。
- 按住小狗拖动，刷新保留位置；双击或 Home / Enter 归位，方向键移动。
- 系统减少动态效果或加入 `?motion=reduce` 可以关闭自动运动。

在本机运行：`python3 -m http.server 8787 --bind 127.0.0.1 --directory examples/mochen`。

公开网址：https://mochenai.github.io/mochen-website-design/
开源仓库：https://github.com/mochenai/mochen-website-design

源文件和部署说明见仓库根目录 README 与 docs/github-pages.md。
