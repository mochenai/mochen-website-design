![Pasted image 20261026105659](media/e0daf8802a3b54c24c40.webp)大家好，我是陌晨。

最近刷到很多3D小岛、水彩晕染、手绘线条风格的动画，我一开始以为是视频模型生成的。

其实很多是AI写的代码。

视频模型直接生成每一帧的像素，代码路线是AI只写程序，画面交给浏览器或渲染引擎一帧一帧算出来，最后拼成MP4。

两者最大的区别在于，视频模型每次抽卡结果都不一样，想改一个细节只能重来。代码渲染100次，100次一模一样，标题往左挪20像素，改一个数字就行。

**可复现、能精确改，是代码视频最值钱的地方。**

下面8个开源项目，每个只讲是什么、解决什么、好在哪。星标数据截至10月21日。

## HyperFrames：写网页就能出视频

HeyGen开源，GitHub 6.8万星。

把视频当网页来写，文字、卡片、动画都用HTML和GSAP，最后由浏览器逐帧截图渲染成视频。

解决的是AI做视频不稳定的问题。模型最擅长写的就是网页，所以出错最少。

好处是上手门槛最低，生态也最丰富，后面提到的rough.js、p5.brush、three.js都能直接塞进来一起用。

`地址：github.com/heygen-com/hyperframes`

## Remotion：用React批量做视频

GitHub 6.5万星。

用React写视频，每一帧是一个组件，组件只认一个输入，现在是第几帧。

解决的是同类视频要反复做的问题。做好一个模板，换一份数据，就是一条新视频。

好处是批量生产、多场景拼接、字幕逐词对齐都很顺。门槛是要懂一点React。

`地址：github.com/remotion-dev/remotion`

## Motion Canvas：按剧本顺序写动画

GitHub 1.9万星。

不用算每一帧长什么样，而是按时间顺序写剧本，先出现什么、再移到哪、最后消失。

解决的是讲解类动画难编排的问题，尤其是代码演示。

好处是自带代码块组件，左边高亮哪一行，右边就执行哪个动作，很多编程教学视频都用它。

`地址：github.com/motion-canvas/motion-canvas`

## rough.js：让线条像手画的

GitHub 2.1万星。

一个手绘风格的图形库，画线时故意加一点随机抖动，再叠两三条略有差别的线。

解决的是代码画面太规整、一眼像PPT的问题。

好处是不用换工具，原来的图形换成它来画，立刻就有铅笔手绘的感觉。**故意画歪一点，反而像人画的。**

`地址：github.com/rough-stuff/rough`

## p5.brush：数字水彩和笔刷

GitHub 1100多星。

基于p5.js的笔刷库，把水彩、铅笔、马克笔、炭笔这些质感打包好了。

解决的是代码很难画出水彩晕染的问题。它的原理是同一个不规则形状叠40多层，每层只有4.5%的透明度，中间深、边缘浅，晕开的感觉就出来了。

好处是不用自己研究算法，调一个笔刷就能用。

`地址：github.com/acamposuribe/p5.brush`

## Manim：数学板书动画

3Blue1Brown作者Grant Sanderson开源，GitHub 9.5万星，社区版另有4.2万星。

把画面里的东西都当成数学对象，曲线是函数，公式由LaTeX渲染。

解决的是公式推导、几何变换这类内容很难做成动画的问题。

好处是公式变形时，相同的符号会自己飞到新位置，做知识类、教学类视频几乎是天花板。

`地址：github.com/3b1b/manim`

## three.js：网页里的3D

GitHub 11.6万星。

在网页里搭3D场景，场景里就三样东西，物体、灯光、镜头。

解决的是想做3D运镜又不会3D软件的问题。给镜头设一条平滑路线，它就顺着路线飞。

好处是跑在网页里，能直接放进HyperFrames一起渲染。

`地址：github.com/mrdoob/three.js`

## Blender MCP：让AI替你操作Blender

GitHub 3.2万星。

一个插件，让AI直接操控Blender，加物体、换材质、打关键帧。

解决的是想要黏土质感、真3D角色，但Blender太难学的问题。

好处是不用学软件，用说话代替操作，AI做完还能自己截图检查，不对再改。

`地址：github.com/ahujasid/mcp-for-blender`

## 怎么选

只学一个，先学HyperFrames。模型写HTML最稳，其他库都能往里装。

要批量做模板，加Remotion。做知识视频，加Manim。要真3D，上Blender MCP。

最后提一个用法，记住这些项目名。跟AI描述需求时，别只说「做个手绘风动画」，直接说「用HyperFrames加rough.js做」。

**你叫得出工具的名字，模型才拿得出对应的本事。**
