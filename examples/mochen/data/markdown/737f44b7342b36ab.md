# 工作流
> 1. 使用Claude code自动安装Excalidraw skill文件
> 2. obsidian安装Excalidraw插件
> 3. Excalidraw微调并导出

## 步骤1:使用Claude code自动安装Excalidraw skill文件

skill文件地址：***https://github.com/axtonliu/axton-obsidian-visual-skills***

可以直接让Claude code安装这个文件，会有对应的安装状态。


![](https://files.mdnice.com/user/75334/d0d362ad-998c-467a-b609-d9b7063c0dfc.png)

其次，我复制内容给到Claude code，并让其生成Excalidraw文件。


![](https://files.mdnice.com/user/75334/baf0a296-a992-4ec3-9c51-2f17d526c368.png)

Claude code中输入 **/excalidraw-diagram** 可直接唤醒。

生成后直接在告诉位置所在地，找到文件后，在obsidian打开。

## 步骤2:obsidian安装Excalidraw插件

打开obsidian，点击左边下面的设置按钮去设置即可。

包括后面找插件也是同理，2张截图我放在一起。

![](https://files.mdnice.com/user/75334/731a35b7-98fb-4c6a-8a0c-19ca057d4e39.png)

安装成功后，启用，这边可以看到Excalidraw 按钮，就成功了已经。

![](https://files.mdnice.com/user/75334/6cdb3f4b-00b0-4473-b861-a9e0cf326fd8.png)

## 步骤3、Excalidraw微调并导出
导入从Claude code生成的内容文件，直接拖拽到Excalidraw即可展示。

排版做微调，支持导出图片、markdown格式。如果可以一键排版就好了，我估计是我的模型选的不好，或是提示词没约束。
