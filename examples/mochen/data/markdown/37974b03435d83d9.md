
清明假期刷到 Andrej Karpathy（前openai/前特斯拉 AI 总监）的一条推文。

讲他怎么用大模型沉淀个人知识库。我非常认可大佬说的：AI 获得的知识在于沉淀在于后期的复用，形成自己的语料知识库。


## 用完即走，太亏了

你是不是这样：

有问题 → 打开 AI → 提问 → 得到答案 → 关闭页面。

下次再问，一切归零。Token 花了，但什么都没留下。
<span class="claudian-embedded-image"><img src="app://e7e77f59dc9fcd6709be0fa01dbcade1f2b6[本机资源路径已省略] alt="notion-para1" loading="lazy"></span>

**这就像买纸巾，擦完就扔。**（看似方便，其实是在持续消耗，没有积累）

更可怕的是：这种模式会让我们越来越懒。


反正随时能问到答案，就懒得整理思路、懒得建立体系、懒得深度思考。Token 消耗了不少，但自己的认知一点没长。

**我们不是在用工具，我们是在买「即食快餐」。**


## Karpathy 的做法：让 Token 变成「投资」

他的思路很简单，但完全反直觉：



> 图：notion-para2



> 不是用 Token 买答案，而是用 Token 生产「可复用的内容」。

具体做法：

- 让 AI 输出 **Markdown**（结构化、可编辑）
- 存进**本地知识库**（变成个人 Wiki）
- 下次调用时**基于已有内容**（持续复利）

通俗来说：**一次投入，终身受益。**

不是每次从零开始问，而是让 AI 基于你沉淀的语料、你的思考习惯、你的表达方式，生成真正属于你的内容。

这不再是「消费 Token」，而是「投资认知资产」。


## 未来的稀缺品：你的「内容分身」

Token 会越来越便宜，通用 AI 内容会泛滥。


> 图：notion-para3



**真正稀缺的是什么？**

**是带个人印记、有认知深度、能持续复用的内容。**

当你把个人经验、思考逻辑、工作方法都沉淀成知识库，你就有了自己的「内容分身」：

- 它懂你的表达风格
- 它记得你过去的思考
- 它能基于你的认知输出内容

**这是别人抄不走的，也是 AI 时代真正的护城河。**


## 分享我的做法

我现在的工作流：

**Obsidian + Claude Code +浏览器剪藏 =个人语料库**

- Obsidian 存所有东西（本地、可控、能关联）
- Claude Code 基于我的语料生成内容
- 个人语料库存着我的框架、风格、复用模板

内容闭环：

```
AI 生成 → 我打磨 → 存进知识库 → 下次基于已有内容调用 → 持续迭代
```

Token 只花在「创作」和「优化」上，而不是重复问答。


## 最后

别再把 AI 当成「答案机」了。

**Token 会贬值，但你的认知资产不会。**

从今天开始，让每一次对话都产生复利。🦞
