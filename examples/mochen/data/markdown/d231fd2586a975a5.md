大家好，我是陌晨。

最近有两个视频 Skill 挺火。一个是花叔的 huashu-art-motion，十月六号发的；一个是歸藏的 guizang-product-video-skill，九月十八号发的。今天中午我看了下，两个加起来 2500 多 Star。

两个我都装了，今天就说说它们能干什么、怎么用、适合什么场景。

它们走的路子和可灵、Seedance 这类视频模型不一样，画面是 Agent 写代码一帧一帧画出来的。

所以画面里的字不会糊，数字不会错；哪段不满意改哪段，不用整条重抽。

**视频模型适合拍你拍不到的画面，代码动画适合讲你讲不清的道理。**

## 1 huashu-art-motion

花叔做的，给它一段口播，它出一支解说动画；只给一个想试的画风也行。MIT 开源。

**功能**

35 种艺术画风，9 种解说动画语法，白板手绘、Vox、3b1b、动态大字、财经图表这些都有。交付 60fps 的 MP4，配乐也是代码合成的。

它不带配音，口播和时间轴要你自己准备好；需要人物出镜的话，得靠生图模型出图，代码负责合成。

下面是我今天跑的三张样张。

![huashu-三方向小样](media/500db922e3806a55c688.webp)

**怎么用**

一行命令装好。

```
npx skills add alchaincyf/huashu-art-motion
```

然后把口播稿交给 Agent，第一句话可以照给。

```
用huashu-art-motion，把我这段口播做成一段白板解说动画，画面跟着口播里的关键词展开，配字幕，最后给我能直接发布的视频。
```

开工前它会先摆出三个画风方向让你挑，上面那三张就是这么来的，挑定了再往下做整片。

有个小坑要知道。它的本地 http 服务是单线程的，容易让 Agent 误以为渲染失败、反复重试，质检里还可能冒出「运动 0.0%」这种假读数，看到了先怀疑它。

**适合场景**

手上有一段录好的口播，或者一个靠嘴说不清的知识点，想让画面跟着讲解走。知识科普、数据解读、读书解说都合适。

花叔自己拿它做过一支五十七秒的诺奖科普，片子里还混了真实影像和插图。他说发到抖音五小时到了十万播放，这是他自报的数，我照此转述。

## 2 guizang-product-video-skill

歸藏做的，给它一个代码库，它出一支宣传片。主体 AGPL-3.0 开源，默认样式那部分归 BSL 1.1，闭源或白标商用要找作者拿授权。

**功能**

读你代码库里的组件和设计风格，整理卖点、写文案、做动画、配乐、配音效，最后给一支 MP4，外加一个能继续改的工程。默认横版中文，45 到 60 秒。

![xhs-04-guizang](media/1a257e440ed62a4916d0.webp)

**怎么用**

装法也是一行。

```
npx skills add https://github.com/op7418/guizang-product-video-skill --skill guizang-product-video-skill
```

在项目目录里跟 Agent 说一句，第一句话可以照给。

```
用 guizang-product-video-skill，把这个项目最近三周的更新做成一支宣传片。横版，45 到 60 秒，中文。先看看代码库自己的组件和设计风格，给我几张关键画面，再继续做动画和声音。
```

它也会先给三个方向让你选，定了再往下做动画和声音。

要有点耐心，我那次从开始到出片等了差不多一个小时。另外有人报过，在 FFmpeg 8.1 下它的混音脚本失控过，四分钟左右写出 112GB 临时文件，磁盘紧张的话跑之前看一眼。

**适合场景**

手里有产品、有版本、有代码库，要做宣传片、版本更新片或者 changelog 推广。

教程类内容也能跑。我九月看到推送的第二天，就拿一篇旧的生视频教程试过，提示词给得很少，它自己在关键截图上打了标注。

## 两个怎么选

手里有产品、有代码库的，用 guizang。手里有口播稿、有个靠嘴说不清的知识点的，用 huashu。



> 图：xhs-06-install



两个都没做到按一下就完事。开工前方向得你自己挑，出片后最好自己从头看一遍再发。

![xhs-03-two-gates](media/196347d39f577b086fee.webp)

如果你手上正好有一段讲了三次别人还没听懂的东西，先做十秒左右的一小段，放回原视频里看看效果。
