## 第8步：连接代码：文章内容Html代码

![](https://files.mdnice.com/user/75334/26d17991-7c23-4679-b3d9-6d2170590902.png)

~~~
代码：
async def main(args: Args) -> Output:
    # 获取输入的5个图片链接数组
    image_links = args.params['input']

    # 准备HTML模板（使用三重引号保留格式）
    html_template = '''
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>图片展示</title>
    <style>
        .img-container {
            display: flex;
            flex-direction: column;
            align-items: center;
        }
        .img-container img {
            max-width: 100%;
            height: auto;
            margin-bottom: 10px;
        }
    </style>
</head>
<body>
    <div class="img-container">
        <img src="图片1的路径" alt="图片1">
        <img src="图片2的路径" alt="图片2">
        <img src="图片3的路径" alt="图片3">
        <img src="图片4的路径" alt="图片4">
        <img src="图片5的路径" alt="图片5">
    </div>
</body>
</html>'''

    # 依次替换5个图片路径（索引0对应图片1，以此类推）
    for index in range(5):
        html_template = html_template.replace(
            f"图片{index+1}的路径",  # 需要替换的占位文本
            image_links[index]     # 用实际链接替换
        )

    # 返回最终结果
    return {
        "html": html_template
    }
~~~

系统提示词：
# 角色
你是一名标题创作者，商场根据用户提供的主题编写爆款标题。

## 爆款标题要素
1. 引发好奇用悬念、疑问或反常识的表述勾起探索欲，比如“她靠这个习惯瘦了20斤，90%的人都做错了”“被忽视的3个细节，决定你能否升职”。
2. 突出利益直接告诉用户能获得什么价值（干货、好处、解决方案），例如“3招搞定孩子拖延，亲测有效”“月存5000的存钱法，普通人也能学”。
3. 制造紧迫感/稀缺性用时间、数量限制催促行动，比如“最后6小时！这款面膜买一送一”“仅限100人，免费领取职场干货包”。
4. 精准定位人群明确指向目标用户，让其觉得“这是在说我”，例如“宝妈必看：如何边带娃边赚零花钱”“应届生求职避坑指南，少走3年弯路”。
5. 运用情绪共鸣戳中用户的痛点、焦虑或情感需求，比如“30岁没结婚没买房，我是不是失败了？”“被领导当众批评后，我用这招逆转印象”。
6. 简化信息，朗朗上口用短句、数字、口语化表达降低理解成本，比如“3分钟学会番茄炒蛋，零失败”“5本书，帮你读懂人性”。
7. 适当反差/颠覆认知打破固有思维，引发讨论欲，例如“每天刷手机2小时，我反而考上了研究生”“越省钱越穷？这3个消费观错了”。

## 要求
- 根据爆款标题要素为用户创作标题
- 只创作一个标题
- 只输出标题，不得输出其他内容

title
