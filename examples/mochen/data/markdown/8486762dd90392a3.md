# 详细步骤
## 步骤1、安装Node.js
- 访问地址：*<u>https://nodejs.org/en/download/</u>*
- 选择对应版本进行安装

![](https://files.mdnice.com/user/75334/d75e0298-b8f5-42af-84f9-f61cafc6de21.png)

- 安装成功后，做下版本验证
  - 以mac为例，打开电脑终端，输入下面信息。
```
node -v
npm -v
```
验证如下：

![](https://files.mdnice.com/user/75334/f21be7cb-2a65-4be5-b4f6-6888f4a169ea.png)

## 步骤2、安装git环境
- 访问地址：*https://git-scm.com/install/mac*
- 根据自己电脑系统来选装对应环境

![](https://files.mdnice.com/user/75334/6273c335-31bc-4396-89f4-8fb00ea528bf.png)

这里面安装完成就好，注意不要修改安装位置，这个需要注意下。

安装好之后，可以输入下面的信息给到终端，看输出内容。这块需要结合AI的帮助来操作，输出的内容可以给到AI来做判断。

```
npm install -g @anthropic-ai/claude-code
````


## 步骤3、安装cc-Switch
这是一个开源的api配置应用，相对来说页面会友好，上手快。

访问地址：
- *https://github.com/farion1231/cc-switch/releases/tag/v3.9.0-3*

![](https://files.mdnice.com/user/75334/7c4676c2-04dd-47e5-bb70-03ac148e1f52.png)

选择新增，如果显示文件损坏，去mac安全中心点击许可。

![](https://files.mdnice.com/user/75334/11857f82-f8de-4c81-853a-69e509639b90.png)

###  步骤3.1、获得智谱apikey
- 访问地址：
https://www.bigmodel.cn/

- 截图如下：
点击新增，创建，获得apikey，把key填入到ccSwitch里面。

![](https://files.mdnice.com/user/75334/388e9659-22f4-424a-a785-f52d1a7acc57.png)

## 步骤4、终端+AI调试
以mac电脑，访问文件，找到Claude文件，这类是隐藏，进入用户，输入「command+shift+.」来看出，这个必须操作。

### 步骤4.1、找到.claude.jason文件
新增一句,如截图
```
"hasCompletedOnboarding": true,
```
