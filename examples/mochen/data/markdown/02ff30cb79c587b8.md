大家好，我是陌晨

看到腾讯云开发者联合机械工业出版社整理了一份 AI 书单，一共 8 本。提示词、Skill、Agent，也有 AI 视频、推荐系统和具身智能。

我按这份书单的介绍看了一遍，觉得可以换个读法。先看你手里的工作卡在哪，再挑对应的书，读完就拿一个真实任务试。

小白如何学 AI，我的回答很明确，要学。

这份书单可以给你一些学习方向。书名里的「数字员工」「变现」，先当成要研究的问题，别直接当成读完后的结果。

![01-换个读法](media/84200d32aab5358b0279.webp)

01

《超级提示词》

写代码时，你会把重复逻辑抽成函数。给 Cursor、CodeBuddy 写提示词，也值得有这份耐心。

需求背景、输出格式这些反复要交代的内容，可以整理成可复用的部分。代码规范变了，就更新对应的内容，保留版本记录，省得下次再靠记忆补。

《超级提示词》介绍的模块化、版本控制和复用，很适合解决这类问题。

我会把它放在起点。你先把给 AI 的输入写清楚，后面才能判断，结果不好究竟是需求没交代明白，还是模型确实做不到。

02

《玩转Skill：零门槛打造你的AI数字员工》

有了能复用的提示词，就可以再往工作流程里走一步。

原书单提到的代码审查、技术文档生成和需求拆解，都适合拿来练手。其中代码审查最容易说明 Skill 的作用，你把团队规范整理进去，告诉它哪些性能问题需要重点检查，发现问题后该怎样给出建议。

执行时有了一份明确的工作说明，你也方便逐项看它有没有做到。

这本书提供的模板和场景，可以帮你起步。我建议先挑一个自己熟悉的任务，做完后有能力判断质量。

数字员工做错了什么，你总得看得出来。

03

《了不起的 Agent Skills：用 AI 创建你的数字员工》

任务一长，Agent 的问题就开始具体了。

中间一步判断错了，后面可能沿着错误继续做。模型反复尝试同一个办法，任务没结束，token 还在花。

这本书会梳理从图灵机到大模型的技术脉络，帮助读者理解 Agent 的能力边界。

我觉得这个方向值得花时间。你要能判断哪些步骤适合让它自主执行，哪些结果必须由人检查，再把任务交出去。

尤其是想用 OpenClaw 串起一套长流程的人，可以先补这部分认知。任务说明写得再详细，也要给失败留处理办法。

04

《智能体：基于大模型的产业实践》

理解了能力边界，下一步就会碰到工程问题。

MCP 给工具接入提供了一套通用协议，但工具接进来之后，模型能否选对工具、参数是否合格，都还需要处理。任务卡住时，系统也得及时发现。

这本书讨论业务 Skill 按需加载，以及参数校验、沙箱隔离等约束机制。循环检测和自验证也在其中。

这些内容对正在做 Agent 开发的人更有用。工具说明没必要一股脑全塞给模型，执行过程也需要留下足够的信息，让你查得出它在哪一步出了错。

05

《一本书讲透 Agentic AI》

Agent 放进公司以后，代码之外还有工作要做。

业务同事需要什么结果，谁来检查，出错后由谁处理，这些事得谈清楚。工程师判断任务完成了，使用它的人未必觉得已经能用了。

这本书涵盖技术原理，也讨论业务应用和组织战略，适合需要把研发与实际使用接起来的人。

我会把它推荐给技术负责人，以及正在推动公司使用 Agent 的同事。你需要让大家对使用范围和质量要求有共同理解，工程方案才好往下做。

用 AI 快速做原型很有价值。准备上线时，再把质量检查和人的决策责任落实进去，这部分工作省不了。

![02-主线五本递进](media/be778647d64b9f739957.webp)

06

《Seedance 变现指南：如何利用 AI 视频赚钱》

如果你的目标是做副业，可以把注意力转到这本。能把重复操作接成自动流程。面对需要持续产出素材的任务，这些能力有用。

但成本也要算完整。

我会把失败重生成和人工修改所花的时间一起记进去，再看交付一条合格视频到底要花多少钱。客户愿意付多少，才决定这单能不能做。

这本书介绍的技术原理、变现路径和投入产出计算，适合带着这些问题读。做出一条好看的视频之后，还要研究怎样持续交付。

07

《推荐系统》

想做与业务指标直接相关的系统，我会认真考虑这本。

推荐系统有大量互联网应用实践，这本书讲的核心算法、系统架构和评估方法，都对应着实际工程工作。

算法工程师可以用它系统补知识。后端和数据工程师也有适合读的部分，特征怎样处理，在线服务怎样搭，A/B 实验怎样判断效果，都值得看。

大模型可以参与多模态理解和长序列建模，原来的推荐系统仍然需要评估这些能力到底有没有改善结果。

读这部分时，可以多看评估方法。模型输出和业务指标怎样接起来，会直接影响你判断一次改动有没有用。

08

《一本书讲透具身智能》

想了解软件之外的方向，可以看具身智能。

机器人需要硬件，也需要感知算法和决策模型。强化学习、sim2real 这些方向，书单也提到了。sim2real 要处理的，就是在模拟环境里学到的能力怎样转到真实环境。

这本书可以帮助你认识技术栈，再判断自己现有的技能能迁移到哪个环节。

我会建议先从仓储物流这样的具体场景看起，弄清机器人要完成什么任务，软件负责哪一段。具体要求看明白了，才方便决定要补什么知识。

跨进软硬件结合的领域，需要补课。先把自己能参与的工作找出来，再决定要不要转向这个领域。

![03-分支三本按目标挑](media/2545597c966ec5cc55cd.webp)

这 8 本不用一起买，也不用按目录挨个读完。

如果你下周还要做代码审查，可以先从 Skill 那本开始，整理一份团队规范，拿同一批代码试一次，再看它漏了哪些问题、哪些建议需要人纠正。

把这次结果记下来，改一版，下一次接着用。就从那件你还得重复做的工作开始。
