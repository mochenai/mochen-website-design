![Pasted image 20261013133736](media/cd0e2d5e573d1f4a5c35.webp)大家好，我是陌晨。

最近 GitHub 上的 AI 项目，涨星速度有点吓人。我挑了20个这个月最热的，挨个看了一遍，发现一个规律：

**一半以上的项目，不是在造新的 AI，而是在给 Agent 补上能干活的手足。**

教它画图、教它少写代码、教它记事、教它别乱装东西。模型够聪明了，现在大家忙的是让它干活更靠谱。

20个太多，我按用途分成了四类，每个只说是什么、解决什么、怎么用。星数为10月12日 GitHub 实时数据。

用法先统一说一句：标着 skill 的，把 GitHub 地址丢给 Claude Code、Codex 这类工具，说"帮我装这个skill"就行。

## 一、装进 Agent 的 skill

**Archify｜8.2万星**

把一段系统描述或者一个代码仓库，画成能点开的交互式架构图。

解决的是"项目太复杂讲不清"。生成的是一个网页文件，同事用浏览器打开，点哪个节点看哪个，还能沿着请求路径一步步看。

用法：装好后说"帮我把这个项目的架构画出来"，画完还能接着让它补步骤、标重点。

`地址：github.com/tt-a1i/archify`

**Ponytail｜16.2万星**

让 Agent 像"最懒的资深程序员"一样写代码。动手前先找现成代码、标准库和平台自带功能，实在没有才自己写。

解决的是 AI 爱重复造轮子、越写越臃肿。**最好的代码，是不用写的代码。**

用法：装上即生效，正常提需求就行。

`地址：github.com/dietrichgebert/ponytail`

**i-have-adhd｜5.7万星**

让 AI 回答先说重点：下一步做什么放最前面，多步任务直接编号，少铺垫少跑题。

解决的是 AI 回复太长、答案埋在第五段。不光写代码，日常问问题也好用。

`地址：github.com/ayghri/i-have-adhd`

**SkillSpector｜2万星**

NVIDIA 开源的 skill 安全扫描工具。装 skill 之前先扫一遍，看有没有偷传文件、暗藏指令、危险代码。

解决的是第三方 skill 来路不明的风险。扫完给一份报告，标出风险等级和具体位置。经常装别人 skill 的，建议先过它这一道。

`地址：github.com/nvidia/skillspector`

**Context Mode｜2.7万星**

让 Agent 读日志、查大文件时，先在一个隔离环境里把内容处理掉，只把有用的结果交给 Agent。

解决的是上下文被垃圾数据塞满，聊着聊着 Agent 就"失忆"了。

`地址：github.com/mksglu/context-mode`

## 二、给 Agent 搭的底座

**Hindsight｜4.9万星**

给 Agent 加长期记忆。存一段对话，它会自动提取里面的人、事、时间和关系，下次需要时再按意思找回来。

解决的是 Agent 每次都从零开始，用户得一遍遍重复背景。适合做客服、做长期陪伴类 Agent 的开发者。

`地址：github.com/vectorize-io/hindsight`

**Paperclip｜10.1万星**

用一个面板管理多个 Agent：每个 Agent 在干什么、目标是什么、花了多少钱，一眼看清。

解决的是 Agent 一多就乱，钱不知道花哪去了。

`地址：github.com/paperclipai/paperclip`

**Cua｜3万星**

给 Agent 一台能操作的电脑，让它看屏幕、点软件、开浏览器，像人一样用电脑。

解决的是很多老软件没有接口，AI 进不去。想让 AI 操作办公软件、做桌面自动化的，重点看这个。

`地址：github.com/trycua/cua`

**Treg｜5100星**

Agent 的工具超市。把搜索、查公司信息、生图、生视频这些外部工具整理成一个目录，Agent 按需查找、按次调用。

解决的是每接一个工具都要单独申请密钥、单独对接。团队买过的服务，还能共享给所有成员的 Agent 用。

`地址：github.com/superdesigndev/treg`

**Worktrunk｜9200星**

一个命令行工具，给每个 Agent 开一个独立的工作目录。

解决的是好几个 Agent 同时改同一份代码、互相打架。同时开多个 Agent 干活的程序员会需要它。

`地址：github.com/max-sixty/worktrunk`

**FreeLLMAPI｜3.4万星**

把几十家模型服务商的免费额度，整合成一个统一接口。某个模型限流了，自动切到下一个。

解决的是个人开发者想试想法，又不想先掏钱。注意它定位是个人实验，免费额度随时会变，别拿来跑正式业务。

`地址：github.com/tashfeenahmed/freellmapi`

**Open Code Review｜4.7万星**

阿里开源的 AI 代码审查工具。读你的代码改动，结合上下文给出精确到行的修改意见。

解决的是代码审查费人、容易漏。可以审刚写的代码、某次提交，或者两个分支的差异。用之前需要先配好模型。

`地址：github.com/alibaba/open-code-review`

## 三、拿来就能用的应用

**WeKnora｜3.4万星**

腾讯开源的团队知识库。把分散的内部文档放进去，就能直接问答检索，还能自动整理成 Wiki。

解决的是公司资料散落各处、新人找不到。支持本地和私有云部署，数据不出门。

`地址：github.com/Tencent/WeKnora`

**Octop｜8900星**

腾讯云开源的 AI 助手，支持多人、多 Agent，能接进网页和飞书，也能挂知识库和外部工具。

解决的是团队想要一个自己能掌控的 AI 助手。

`地址：github.com/TencentCloud/Octop`

**OpenMAIC｜4.1万星**

清华团队开源的 AI 课堂。给一个主题或上传资料，生成带幻灯片、测验和互动的课程，生成后还能继续改。

解决的是备课慢。做培训、做知识付费的可以试试。

`地址：github.com/THU-MAIC/OpenMAIC`

**HyperFrames｜6.2万星**

HeyGen 开源的视频工具，用网页代码做视频：Agent 写好 HTML 和动画，直接渲染成 MP4。

解决的是做产品介绍、字幕动画要开剪辑软件。说清楚想要什么，让 Agent 写、预览、改，循环几轮就出片。

`地址：github.com/heygen-com/hyperframes`

**Financial Services｜4万星**

Anthropic 官方出的金融插件包，把行业研究、财报分析、建模、对账拆成一个个插件。

解决的是金融从业者的重复案头工作。比如让它围绕一个行业整理竞争格局，或者根据新财报更新模型、起草分析笔记。

`地址：github.com/anthropics/financial-services`

**Knowledge Work Plugins｜2.9万星**

Anthropic 官方出的岗位插件包，按销售、客服、产品经理等岗位分好了，主要给 Claude Cowork 用，Claude Code 也兼容。

解决的是不知道 AI 在自己岗位上能干嘛。按岗位挑插件，再按公司的资料和习惯改一改。

`地址：github.com/anthropics/knowledge-work-plugins`

## 四、好玩的和做开发的

**God's Eye View｜5.4万星**

一个浏览器里的 3D 地球，把飞机、船、卫星、地震这些公开数据实时画上去，像在用间谍卫星看世界。

不解决什么具体问题，纯粹好玩，点哪看哪。

`地址：github.com/bilawalsidhu/gods-eye-view`

**GPUI Kit｜1.7万星**

用 Rust 写桌面软件的界面组件库，按钮、表单、表格、可拖动的面板、代码编辑器都有现成的，Mac、Windows、Linux 通用。

解决的是做桌面应用要从零搭界面。适合 Rust 开发者，项目里有示例程序，可以先看效果。

`地址：github.com/longbridge/gpui-kit`

## 写在最后

普通人不用全装。我的建议是：先装 i-have-adhd 和 SkillSpector，一个让 AI 说话更干脆，一个帮你把好安装关；做内容的再加 HyperFrames 和 Archify。

一年前大家比的是谁的模型更强，现在 GitHub 上最火的，是让 Agent 少犯错、少浪费、少失忆的东西。

**AI 已经够聪明了，现在缺的是规矩。**
