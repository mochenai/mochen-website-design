![Pasted image 20261013140455](media/f1e60da3392e63d7cc35.webp)大家好，我是陌晨。

用AI写东西，最常见的问题不是写错，而是写得太"对"了。

句子通顺，逻辑完整，挑不出毛病，可读完就是不像人话。一眼AI味。

以前的办法是攒一堆"去AI味提示词"，每次复制粘贴，改完下次又找不着。现在有了skill，一次装好，以后说一句"帮我去下AI味"就行。

>目前觉得最好的AI味还是具备更多的内容语料，上下文的内容沉淀，以及框架的约束，这样会更好。

skill可以理解成提前写给AI的一份操作手册。装进 Claude Code、Codex、WorkBuddy、豆包工作这类工具里，它就默认按这套规矩干活，不用每次从头教。

今天分享5个GitHub上开源的去AI味skill，大家可以对照着来使用。

## Humanizer-zh

英文爆款 Humanizer 的汉化版，GitHub 1.9万星，目前最火的一个。
![QQ_1791703910756](media/1d1cf3305f3f11f51b83.webp)

它干的事很直接：把中文里那些一看就是AI写的痕迹挑出来清掉，比如堆砌的排比、空洞的总结句、过度的"首先其次最后"。

已经有一版初稿、只想让它读着自然点，交给它最省心。周报、邮件、润色都能用。**拿不准选哪个，先装它。**

`安装地址：github.com/op7418/Humanizer-zh`

## human-writing

数字生命卡兹克开源的，4000多星，也是我自己写作流程里一直在用的那个。
![QQ_1791703932561](media/7fd7b896c128fc5c354c.webp)

它的思路跟上一个不一样，不只是换词，而是让文字像一个具体的人在说话。素材不够的时候它会直接提醒你，不会硬给你凑字数。

适合公众号、观点文、带个人经历的长文。做自媒体的，优先试它。

`安装地址：github.com/KKKKhazix/human-writing`

## 说人话（shuorenhua）

2000多星，主打职场场景。

它改稿的顺序是先锁事实，再动语气。数字、结论、谁负责什么，这些先固定住，然后才去删套话。

所以特别适合周报、项目总结、会议纪要这类内容。**改得再顺，意思改错了就是事故**，怕这个的直接用它。

`安装地址：https://github.com/MrGeDiao/shuorenhua`

## qu-ai-wei

专门收拾"翻译腔"和"模板味"。

有些稿子每个词都没毛病，整段读下来就是一股被套过模板的感觉。它会动段落结构，不只是替换几个词。

适合AI直接吐出来、读着很顺但很假的长文初稿。

`安装地址：github.com/LifelongLazyLearner/qu-ai-wei`

## lieflat-less-ai-tone

2600多星，最"讲证据"的一个。

作者拿约283万字的人类文章和AI文章做对比，统计出哪些特征真的更像AI，再写成规则。不是凭感觉列清单。

像"不是A，而是B"这种句式、密集的破折号、段落开头先来一句空评价，它抓得比较准。想要有依据的去味，选它。

`安装地址：github.com/larashero3-dotcom/lieflat-less-ai-tone`

## 怎么安装

最简单的方式，打开你常用的AI工具（Claude Code、Codex、WorkBuddy、豆包工作都行），把GitHub地址丢给它，说一句：

```
帮我安装这个skill https://github.com/op7418/Humanizer-zh
```

装好后，写完东西直接说"用 Humanizer-zh 帮我去掉这段的AI味"就行。

习惯用命令行的，也可以一行装好：

```
npx skills add op7418/Humanizer-zh
```

其他四个，把后面的仓库名换掉就行。

## 怎么选

不用五个全装，**两个就够**。

日常润色、周报总结：Humanizer-zh 打底，职场文档再加说人话。

公众号、小红书这类要人味的：human-writing 打底，想更稳再加 lieflat-less-ai-tone。

最后说一句，skill能去掉AI味，但去不掉"没东西可写"。**观点和经历得是你自己的，AI只负责让它读起来像你。**
