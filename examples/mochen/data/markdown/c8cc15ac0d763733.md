大家好，我是陌晨。

我相信，大家会遇到我这种情况：一篇文章写好后，想给文字做配图，想尝试AI 直出，又在提示词犯难；市面有完整的 skll 配图工作流，但自己感觉又不好上手。经常性犯难，导致后面草草配图。

既破坏写作后的输出激情，又破坏内容质量。

今天我分享自己正在用的4 类配图方法，每一个都是自己在用。

## baoyuskill

地址：`https://github.com/JimLiu/baoyu-skills/blob/main/README.zh.md`

这个 skill 相比大家都知道，基本涵盖配图➡️排版➡️发布的全工作流，我全部安装好了但坦白讲，成本真是不低，配图模型一般是 nanobanana ，单一张就要几毛，换成百炼的，效果不行的同时还需要 3 毛一张，算了，直接放弃。我这种没阅读量、没商业性的日常笔记真是配不上。


![QQ_1776313985240](media/c4c3273c2481829380a0.webp)

## excalidra skill🌟
地址：`https://github.com/axtonliu/axton-obsidian-visual-skills`
这个我目前用的最多，主要是比 nanobanana 便宜，所以我一般是内容生成后，直接做内容分段，生成excalidra文件，然后导出/截图上传。其实excalidra会输出markdown 文件，所以在 markdown 格式预览就可以看到图片长啥样了，非常不错。
![QQ_1776313885775](media/2a697038d85f3f17935e.webp)

## chart-craft-plus🌟
地址：`没找到，需要找我私发，下面可以找到我`

这个会自动生成HTML 文件，直接在你本地打开，35+格式，各类表的形式都有，非常好用。使用方式很简单，这边的 skill 放了个灵活的提示词，会根据内容做自动匹配。可以截图转发，很方便的，也可以使用 HTML 转 png 工具直接转。
