![Pasted image 20261027181126](media/b9c83195c13df8e05ea1.webp)大家好，我是陌晨。

最近skill越装越多，本地已经堆了几十个。

装得多不代表用得上。很多skill看着厉害，真跑起来token没少烧，活却没干明白。而且skill装太多，Agent每次干活都要先翻一遍说明书，反而更慢。

>skill不是越多越好，是一个场景配一个就够。

所以今天只挑5个，各管一个场景：做网页动效、画知识图谱、写营销文案、做产品视频、整理会议纪要。

## GSAP Skills

GSAP是一个老牌的网页动画库，GSAP Skills是它官方出的skill，GitHub 1.6万星。
![QQ_1791774821450](media/78ae93583790e88b8a48.webp)

解决的问题很具体：让AI写网页时，动效别再乱来。首屏入场、元素依次出现、滚动触发、页面转场，这些动画它都有现成的写法规范，AI照着做，不容易出现卡顿和花里胡哨的效果。

里面拆成了8个子skill，各管一块，组合起来能做一个完整的落地页。

经常用AI做官网、产品页的，装它。

`安装地址：github.com/greensock/gsap-skills`

## Research-to-Diagram

一句话做调研，直接出关系图谱。
![QQ_1791774851464](media/70c739256db0c559c512.webp)
你给它一个主题，比如"安史之乱主要军事集团的人物关系"，或者"某个产品的功能体系"，它会先搜资料、理清人物和逻辑关系，再输出一份研究报告和一张知识图谱，最后打包成PDF。

适合两种情况：一是快速进入一个陌生领域，二是汇报前把一堆零碎资料理清楚。**看十篇文章不如看一张图。**

`安装地址：github.com/wshuyi/research-to-diagram`

## copywriting

专门写营销文案的skill，产品标题、卖点、活动文案、产品首页都能用。

它不会上来就写，而是先问你定位、目标用户、核心数据，确认清楚再动笔。写出来的东西更具体，少了"赋能""一站式"这类空话。

它来自 marketingskills 这个营销工具包，整包5.4万星，里面还有SEO、转化率优化、数据分析等几十个营销skill。经常写产品材料的，可以直接装整包，按需调用。

`安装地址：github.com/coreyhaines31/marketingskills`

## guizang-product-video-skill

归藏出的产品视频skill，把产品资料直接变成宣传视频。

很多人用AI做了小工具、小demo，最后卡在"怎么给别人看"。截图太散，录屏太糙，PPT太土。

这个skill可以吃进你的代码库、产品文档、截图或录屏，自己出分镜、写文案、做画面和动效、配乐配音效，最后导出成片。**以前要一个剪辑师干两天的活，现在丢给Agent等着就行。**

适合产品已经有文档或代码，准备对外展示的时候用。支持 Claude Code 和 Codex。

`安装地址：github.com/op7418/guizang-product-video-skill`

## meeting-notes

整理会议纪要的skill，来自 claude-office-skills 这个办公skill合集。

把会议录音转出来的文字丢给它，它会按议题、结论、待办、负责人这些维度整理成结构化纪要。嫌太长，再说一句"总结成一段话"就行。

会多的人，装上能少熬不少夜。

`安装地址：github.com/claude-office-skills/skills（在 meeting-notes 文件夹里）`

## 怎么安装

最省事的办法，打开你常用的AI工具，Claude Code、Codex、WorkBuddy都行，把GitHub地址丢给它，说一句：

```
帮我安装这个skill https://github.com/greensock/gsap-skills
```

装好后直接用大白话下指令，比如"用GSAP skill帮我做一个产品落地页"。

习惯命令行的，也可以一行装：

```
npx skills add greensock/gsap-skills
```

其他几个把仓库名换掉就行。

最后说一句，skill本质上是把一个重复的工作习惯打包好交给AI。**先想清楚自己哪件事天天在重复做，再去找对应的skill，别反过来。**

这5个是我觉得各场景里最值得装的，如果你有更好用的skill，也欢迎**评论区分享。**
