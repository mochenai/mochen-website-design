![Pasted image 20261105125727](media/032fb983ac7724b0056a.webp)`claude-slides`大家好，我是陌晨。

这段时间后台问得最多的一个问题，是我那套内容工作台是如何搭建？

我每次都想认真回，但一打字就发现，这事儿没法一句话讲完。

因为它不是某一个神器，而是一堆工具咬合在一起转起来的。

先给你一个我自己踩了很久才悟到的判断。

工具这东西，值钱的从来不是数量，是能不能串成一条链。 一个采集、一个生产、一个分发，单拎出来都平平无奇，可一旦前一个的出口刚好是后一个的入口，它就不再是工具，是一条生产线了。


1. ## anytocopy｜把链接变成文字稿
    

各大社媒的视频，音频，网页文章，丢个链接进去就能快速转成文字。

它最合我意的点是支持 CLI 命令行，能直接写进我自己的脚本和自动化流程里。对普通人它是个取文案的网页工具，对我它是整条链的第一道进水口。

我的 creator-buddy 数据层，一半的功劳在它身上。

地址：`anytocopy.com`
![01-anytocopy](media/ed5da6c422fa78142b4a.webp)
  

2. ## gauikei｜用 API 把全网社媒数据抓下来
    

如果说 anytocopy 负责把单条内容转文字，gauikei 负责的是批量。

它以 API 的形式获取任意平台的社媒内容，点赞，收藏这些互动数据能直接调，文章和视频也能通过接口下载。

creator-buddy 的数据层核心，就是它和 anytocopy 这对组合。一个管抓取，一个管转写，我后面所有的选题和二创，吃的都是它俩喂进来的料。

地址：这工具比较小众，直接搜 gauikei 就能找到，以你手里在用的版本为准

  ![02-gauikei](media/b3226f3be2faa5a4fd81.webp)

3. ## 蚁小二分发｜国内外多平台一键分发
    

一篇内容，同步推到几十个账号后台。

我现在日常主要用自己写的 skill 来发，但真要论稳定性，还得是它。写代码的人都懂，自己搓的轮子图个顺手，可关键时刻不掉链子的，往往是人家打磨了好几年的成品。

不想折腾自动化的朋友，直接上它，省心。

地址：`yixiaoer.cn`

  ![03-蚁小二分发](media/c85a5691396b5b7b4eba.webp)

4. ## 飞书排版插件｜飞书文章一键排成平台图文
    

这是个 chrome 插件。

我很多初稿是在飞书文档里写的，写完最头疼的就是搬运。这个插件能把飞书里的文章一键排成小红书图文和公众号文章，内置好几种排版格式，自动适配两个平台的版式，排完一键导进小红书和公众号后台就能发。

地址：chrome 应用商店搜飞书排版即可安装

  ![04-飞书排版插件](media/5ac1052c6c7ab2efd718.webp)

5. ## X 文章导入插件｜一键同步到 X
    

同样是 chrome 插件，专门治一个病。

X 上传图片只能一张一张手动传，长文搬运简直是酷刑。这个插件能把我在本地，飞书和公众号里写好的文章，一键导入 X 并发布，自动排版，图片也帮你处理好。

一个把我从重复劳动里捞出来的小东西，但越是这种小东西，越是每天都离不开。

地址：chrome 应用商店搜 X 文章导入或 X article 即可

  ![05-X文章导入插件](media/e55d474e102e4e060cc2.webp)

6. ## magpie｜所有模型 API 的统一转接器
    

这个是我今年的年度最佳，没有之一。

你可以把它理解成一个模型 API 的转接器，市面上用得到的模型平台，Agent，全部能统一对接进来。比如在 DeepSeek Harness 里，我通过它把 gemini，codex，opencode 等任意平台的 API 接进来，一个 Agent 调度好几家模型，哪个便宜好用用哪个。

过去换个模型要改一堆配置，现在在菜单栏点一下就切完了。这种工具一旦用上，就回不去了。

地址：`usemagpie.ai`

  ![06-magpie](media/fbcba9595ce9528b624f.webp)

7. ## DeepSeek Harness｜能自己 DIY 插件的 Agent
    

简称 DSH，我最近的主力开发工具，搭配 DeepSeek 4.1 Flash 用，效果出奇地好。

它最戳我的是插件能自己 DIY，我能亲手做各种插件，照着自己的习惯改造整个开发工作流。工具顺不顺手，很多时候不看它开箱多强，看它让不让你改。

我具体怎么把 DSH 改造成现在这样，之后单独写一篇细讲。

地址：GitHub 搜 DeepSeek Harness，官方仓库在 deepseek-ai 下

  ![07-DeepSeek-Harness](media/f3c536939bab9b664509.webp)

8. ## egolite｜给 AI Agent 专用的浏览器
    

我自己日常浏览还是用 chrome，但我的 Agent 干活，用的是 egolite。

Agent 登录账号，自动发内容这些活儿，全在这个独立浏览器里完成。人和机器各用各的，互不打架，账号也更安全。

说人话，就是我给我的数字员工单独配了一间办公室，它在里面怎么折腾，都不会碰到我自己的东西。

地址：`egolite.ai`

  ![08-egolite](media/12f457209a970967b306.webp)

9. ## grokbot｜在手机上远程调度 Agent
    

周末人在外面逛，我照样能用它在手机上远程调度我那几个 Agent，让它们帮我跑任务，处理工作。

不在电脑前，事情也能往前推。对一个习惯了随时冒出想法的人来说，这种随手就能把活儿派出去的感觉，太爽了。

我的具体用法也值得单开一篇教程。

地址：`cursor.com/cn/download/bot`

  ![09-grokbot](media/dde315ac56a15c98ee3e.webp)

10. ## UU 远程控制｜免费轻量的远程桌面
    

用 Agent 之后，我移动办公的需求肉眼可见地变多了。

uu 远程免费，轻量，手机端和电脑端的操作体验都挺顺。就盼着它别哪天也学向日葵，ToDesk，越做越臃肿，广告越弹越多。

能白嫖又好用的东西不多了，用一天是一天。

地址：`uuyc.163.com`

  ![10-UU远程控制](media/7a3b6c9f50da15a6f9fe.webp)

## 最后

你再回头看这 10 个。

anytocopy 和 gauikei 负责把料抓进来，magpie 和 DSH 负责把内容生产出来，蚁小二和两个插件负责把成品送出去，egolite 和 grokbot，UU 远程，负责让这整条链不管我人在哪儿都能转。

单看每一个，都只是个趁手的小工具。可当它们首尾咬合，我一个人的产能，就被硬生生撑开了好几倍。

真正拉开差距的，从来不是谁手里的工具更多，而是谁先把工具串成了系统。

工具会一直更新换代，但搭系统的这个思路，是能跟着你复利增长的东西。

这 10 个是我现在每天都在摸的家伙，你要是有更好用的，也欢迎评论区甩给我。

我是陌晨，下次见。
